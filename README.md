# LiteNote

A lightweight Notepad-style text editor for Ubuntu/Linux, built with Python 3 and Tkinter.

## Features
- New, Open, Save, Save As
- UTF-8 text files (including Persian text)
- Undo / Redo, Cut / Copy / Paste, Select All
- Find Next
- Toolbar and menus
- Word Wrap toggle
- Font zoom
- Line, column, word and character count
- Warning before discarding unsaved changes

## Requirements
- Ubuntu Desktop (or another Linux desktop)
- Python 3
- Tkinter

On Ubuntu, if Tkinter is not installed:

```bash
sudo apt update
sudo apt install python3-tk
```

## Run

Open a terminal in the extracted project folder and run:

```bash
python3 litenote.py
```

Or:

```bash
chmod +x litenote.py
./litenote.py
```

## Keyboard shortcuts

| Action | Shortcut |
|---|---|
| New | Ctrl+N |
| Open | Ctrl+O |
| Save | Ctrl+S |
| Save As | Ctrl+Shift+S |
| Find | Ctrl+F |
| Select All | Ctrl+A |
| Undo / Redo | Ctrl+Z / Ctrl+Y |
| Zoom In / Out | Ctrl++ / Ctrl+- |
